内容管理入口

本站托管在 GitHub Pages，不需要额外服务器。登录 GitHub 后，通过下面的入口修改文字或上传图片；提交后网站会自动重新发布。

文字、项目、经历、链接编辑网站内容打开 GitHub 编辑器 ↗ 头像、项目截图、GIF 等上传媒体文件打开 assets 文件夹 ↗ 适合同时修改多个文件高级在线编辑打开 github.dev ↗ 查看发布是否成功部署状态查看 Actions ↗

最常用的更新流程

  1. 点击“编辑网站内容”，登录 GitHub。
  2. 在 content.js 中修改对应的中文或英文内容。
  3. 点击右上角 Preview changes 检查改动。
  4. 点击 Commit changes 保存；通常几分钟后网站自动更新。

安全说明：此页面不保存密码或访问令牌，也没有独立数据库。权限完全由你的 GitHub 账号管理。
